# ✨ Jyotish Numero – Free Horoscope & Numerology App

A free, browser-based app for Vedic horoscope, numerology, name analysis, mobile number checking, Lo Shu guidance, and Dasha insights.

**Built by Venkateswara Rao Banday**

---

## Overview

Jyotish Numero is a single-page astrology and numerology app designed to help users explore:

- Driver and Conductor numerology
- Chaldean name analysis
- Mobile number suitability reading
- Lucky number and missing-number remedies
- Vedic birth chart basics
- Vimshottari Dasha timeline
- Sade Sati awareness
- Chinese Bagua-style number interpretation

It is built for quick use with no sign-up and works fully in the browser.

---

## Features

- Core numerology calculations for Driver, Conductor, soul urge and personality number
- Driver–Conductor combination insights and life/career guidance
- Divine meaning, deity, mantra, remedy, gemstone and lucky colour/day suggestions
- Lo Shu grid and missing-number remedies
- Name correction suggestions based on traditional Chaldean compatibility
- Mobile number suitability score with positive/negative pair analysis
- Chinese zodiac and Bagua Shuzi interpretation for lucky numbers
- Vedic chart basics: Lagna, Moon sign, Sun sign, Nakshatra and Dasha timeline
- Place search worldwide with automatic latitude, longitude and time zone input

---

## Privacy

All calculations run in your browser. Your birth details, name and phone number are not uploaded or stored. The only external request is the optional place search via the Open-Meteo geocoding API.

---

## Run locally

It is a single HTML file with no build step.

- Download `index.html`
- Open it in any modern browser
- Or publish to GitHub Pages by hosting the file in a repository and enabling Pages

---

## How it works

- Numerology follows Chaldean values and reductions.
- Driver is the day of birth reduced to a single digit.
- Conductor is the sum of the full birth date digits reduced to a single digit.
- Astrology sections use simplified sidereal calculations and traditional interpretations.
- Place search uses the free Open-Meteo geocoding API.

---

## Limitations

- The app is designed for guidance and self-reflection, not medical or professional advice.
- Some astrology values are traditional approximations and may vary by source or method.
- Nakshatra and chart boundaries can shift slightly depending on exact birth timing and location.
